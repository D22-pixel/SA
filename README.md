Sistema para Academia (SA)
O SA é um software de gestão projetado para centralizar o controle operacional, financeiro e técnico de uma academia.

🎯 Objetivo
Otimizar a gestão administrativa através de cadastros interligados de alunos, planos e pagamentos.

🛠️ Especificações Técnicas

Linguagem: Java.

Banco de Dados: MySQL.

Interface: Web (Compatível com Chrome, Firefox e Edge).

👥 Perfis de Usuário

O sistema possui controle de acesso por cargo:

Gerente: Acesso total ao sistema e relatórios.

Recepcionista: Gestão de alunos, matrículas e check-in.

Financeiro: Controle de pagamentos, fornecedores e receitas.


Professor: Consulta de fichas de treino e históricos.

📑 Funcionalidades Principais

Cadastros: Alunos (CPF obrigatório), Planos, Fornecedores e Funcionários.

Vendas: Registro de matrículas vinculando aluno, plano e pagamento.

Relatórios: Listagem de alunos ativos e controle de receitas por período.

Segurança: Autenticação via login e senha para todos os funcionários.

⚡ Diferenciais (Requisitos)

Agilidade: Resposta do sistema em até 3 segundos.

Escalabilidade: Suporte para crescimento de dados e usuários.
